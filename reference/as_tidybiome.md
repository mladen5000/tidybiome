# Coerce Objects to tidy_microbiome

Coerce Objects to tidy_microbiome

## Usage

``` r
as_tidybiome(x, ...)
```

## Arguments

- x:

  An object to coerce (e.g. from `phyloseq`, `TreeSummarizedExperiment`,
  or `matrix`).

- ...:

  Additional arguments passed to methods.

## Value

A `tidy_microbiome` object.
