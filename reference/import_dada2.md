# Import DADA2 Pipeline Outputs into tidy_microbiome

Ingests sequence table and taxonomy matrices generated by the DADA2
pipeline, converting sample-by-sequence matrices into a synchronized
`tidy_microbiome` container. Optionally shortens long DNA sequence
column names to clean identifiers (e.g. `ASV0001`) while preserving full
nucleotide sequences in the taxonomy table.

## Usage

``` r
import_dada2(seqtab, taxa = NULL, sample_metadata = NULL, clean_names = TRUE)
```

## Arguments

- seqtab:

  A matrix, data frame, or path to an RDS/TSV file containing DADA2
  sequence table (samples as rows, ASV sequences as columns).

- taxa:

  Optional matrix, data frame, or path to an RDS/TSV file containing
  taxonomy assignments (ASVs as rows, taxonomic ranks as columns).

- sample_metadata:

  Optional data frame or path to a TSV/CSV file containing sample
  metadata.

- clean_names:

  Logical. If `TRUE` (default), converts long nucleotide sequences into
  clean `ASV001`, `ASV002`... identifiers and preserves sequence strings
  in taxonomy column `sequence`.

## Value

A `tidy_microbiome` object.
