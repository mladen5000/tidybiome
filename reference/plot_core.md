# Plot Core Microbiome Landscape

Visualizes the core microbiome distribution across prevalence and
abundance.

## Usage

``` r
plot_core(core_res)
```

## Arguments

- core_res:

  A data frame or tibble produced by
  [`calc_core_microbiome()`](https://tidybiome.org/reference/calc_core_microbiome.md).

## Value

A
[`ggplot2::ggplot`](https://ggplot2.tidyverse.org/reference/ggplot.html)
object.
