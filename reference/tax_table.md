# Extract Taxonomy Table from tidy_microbiome

Extract Taxonomy Table from tidy_microbiome

## Usage

``` r
tax_table(x, ...)
```

## Arguments

- x:

  A `tidy_microbiome` object.

- ...:

  Additional arguments (not used).

## Value

A
[tibble::tbl_df](https://tibble.tidyverse.org/reference/tbl_df-class.html)
with taxonomic lineage annotations.
