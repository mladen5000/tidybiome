# Modern Minimalist Publication Theme for tidybiome

Modern Minimalist Publication Theme for tidybiome

## Usage

``` r
theme_tidybiome(base_size = 11, base_family = "")
```

## Arguments

- base_size:

  Base font size (default: 11).

- base_family:

  Base font family.

## Value

A `ggplot2` theme object.
