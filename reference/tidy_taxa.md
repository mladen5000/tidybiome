# Extract Taxonomy Annotations as a Tidy Tibble

Extract Taxonomy Annotations as a Tidy Tibble

## Usage

``` r
tidy_taxa(tb)
```

## Arguments

- tb:

  A `tidy_microbiome` object.

## Value

A
[tibble::tbl_df](https://tibble.tidyverse.org/reference/tbl_df-class.html)
with `taxon_id` and taxonomic ranks.
