# tidybiome: Tidyverse-Native Modern Microbiome Analysis Suite

A modern, tidyverse-native Swiss Army knife for downstream microbiome
analysis. Implements state-of-the-art bioRxiv and literature
methodologies for compositional transformation (Robust CLR), alpha
diversity (unified Hill numbers profile), beta diversity (Robust
Aitchison, Tree-Wasserstein, UniFrac), ordination (RPCA, cPCA),
multi-engine consensus differential abundance testing, constrained
ordination (db-RDA), and microbial co-occurrence networks.
