# Convert tidy_microbiome to S7 Formal Object

Coerces an S3 `tidy_microbiome` object to a next-generation S7 formal
object with typed properties and validation contracts.

## Usage

``` r
to_s7(tb)
```

## Arguments

- tb:

  A `tidy_microbiome` object.

## Value

A `tidybiome::tidy_microbiome_s7` object.

## Examples

``` r
if (requireNamespace("S7", quietly = TRUE)) {
  data(gut_microbiome)
  tb_s7 <- to_s7(gut_microbiome)
  print(tb_s7)
}
```
