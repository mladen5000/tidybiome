# Validate Integrity of a tidy_microbiome Object

Validate Integrity of a tidy_microbiome Object

## Usage

``` r
validate_tidy_microbiome(tb, verbose = FALSE)
```

## Arguments

- tb:

  An object to validate.

- verbose:

  Logical. If `TRUE`, prints a confirmation message upon successful
  validation. Defaults to `FALSE`.

## Value

`TRUE` if valid, otherwise throws an error.
